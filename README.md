# CODSOFT Task 3 - Smart To-Do List Manager

A Python-based task management application that helps you prioritize your work using the **Eisenhower Matrix** (Urgent/Important Quadrants).

## 🎯 Overview

This To-Do List Manager uses the Eisenhower Matrix framework to help you categorize and prioritize tasks based on two dimensions: 
- **Urgent** vs **Not Urgent**
- **Important** vs **Not Important**

Tasks are automatically sorted into four quadrants:
- **Q1: DO FIRST** 🔥 (Urgent & Important) - Handle immediately
- **Q2: SCHEDULE** 📅 (Important, Not Urgent) - Schedule for later
- **Q3: DELEGATE** 🤝 (Urgent, Not Important) - Delegate if possible
- **Q4: ELIMINATE** 🗑️ (Neither) - Avoid or eliminate

## 📋 Features

- ✅ **Add Tasks** - Create new tasks with urgency and importance classification
- 📊 **View Tasks** - Display all tasks organized by priority quadrant
- 🎨 **Smart Prioritization** - Automatically categorizes tasks using the Eisenhower Matrix
- ✨ **User-Friendly Interface** - Simple command-line menu for easy navigation
